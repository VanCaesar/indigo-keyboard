装好后（只需做一次）

  1. 打开 设置 → 隐私与安全性 → 开发者模式，打开后手机会重启
  2. 设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任
  3. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 选「靛蓝」
  4. 点进「靛蓝」，打开 允许完全访问（震动要用）

每周重签

  1. 爱思助手 → IPA 签名 → 用 Apple ID 签名 Indigo-unsigned.ipa
  2. GitHub 仓库 → Releases → 新建，tag 填 signed-日期，拖入签好的 IPA → Publish
  3. 等 1–2 分钟，回到本页点安装
